# 项目网页

GitHub Pages 继续使用 `docs/`，无需构建步骤或外部运行依赖。

- `index.html`：项目首页、安装方式、通知渠道与常见问题。
- `demo.html`：独立的 16:9 场景演示，同时嵌入首页。
- `assets/site.css` / `assets/site.js`：首页样式、主题、安装标签和复制命令。
- `assets/demo.css` / `assets/demo.js`：演示画面与 40 秒时间轴。
- `dsh-index.json`：现有插件索引，网页改版不改变此地址或内容。

## 本地预览

在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/docs/`。独立演示位于 `http://localhost:8000/docs/demo.html`，可以使用播放器的全屏按钮。首页的“打开宽屏演示”在新标签页打开该页面。

## 场景与审阅入口

演示的时间经过压缩。短通知场景展示独立会话并行、系统提醒、用户手动切回会话和继续输入；长通知场景展示离席、回合结束、5 分钟未响应后的飞书消息，以及回电脑验收。通知不是会话直达链接，页面也不会请求系统通知权限或发送真实消息。

| 相对 URL | 审阅画面 |
| --- | --- |
| `demo.html?t=5&paused=1` | 右上角 macOS 风格通知 |
| `demo.html?t=10&paused=1` | 手动选中需要回复的会话 |
| `demo.html?t=15&paused=1` | 继续输入，取消待发提醒 |
| `demo.html?t=25&paused=1` | 手机锁屏收到飞书通知 |
| `demo.html?t=29&paused=1` | 打开消息，看到项目与结果摘要 |
| `demo.html?t=36&paused=1` | 返回电脑验收结果 |
| `demo.html?scene=away` | 从离席场景开始播放 |

`t` 单位为秒，范围 0–39.9；`paused` 参数用于暂停审阅。播放、暂停、重播、进度拖动、章节切换均可直接操作。

## 主题与播放行为

默认跟随系统浅色／深色偏好。首页和演示页均可切换“自动 → 浅色 → 深色”，选择保存在 `localStorage` 的 `cc-notify-theme` 中；存储不可用时仍可在当前页面切换。

首页通过校验来源的 `postMessage` 同步嵌入演示的主题与可见状态。演示离开首页可视范围、标签页隐藏或屏幕过窄时暂停，恢复后接着播放，不跳过时间。开启“减少动态效果”时默认暂停，用户仍可主动播放。手机竖屏显示横屏引导，安装说明在竖屏下仍可阅读。

## 修改后的检查重点

1. 浅色、深色与系统自动模式下，首页和演示主题一致。
2. 两章顺序播放、循环、暂停、拖动、重播和全屏正常；降低动态偏好得到尊重。
3. 桌面通知在右上角出现；鼠标选择会话标签，不点击通知跳转。
4. 手机先收到通知，再打开消息，最后切回电脑；信息与真实通知字段一致。
5. 竖屏提示、横屏恢复与窄屏安装区均正常。
6. 四个安装标签支持方向键、Home、End，复制成功有反馈；剪贴板不可用时可手动复制。
7. 禁用 JavaScript 后仍能阅读全部安装命令；相对资源路径在 `/cc-notify-hooks/` 子目录下可用。

快速语法检查：

```bash
node --check docs/assets/site.js
node --check docs/assets/demo.js
git diff --check
```
